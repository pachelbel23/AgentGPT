## 2025-07-24 - Optimizing Agent and Task database creation and React list components
**Learning:** Sequential 1+N database writes in high-frequency creation paths (like Agent creation with many AgentTasks) can be significantly slow and prone to race conditions or partial failures. Consolidating them into a single nested Prisma create query reduces latency from ~351ms to ~15ms (a ~95% improvement) and guarantees database atomicity. Additionally, chat-based list components (like ChatWindow and TaskWindow) with animation wrappers can suffer from O(N) re-render cascades as items are added. Wrapping item components in React.memo and providing full dependency arrays to hooks (like scroll useEffects) ensures the main thread is never blocked and rendering is lightning-fast.
**Action:** Always favor nested Prisma writes or bulk operations for related database updates, and ensure that dynamic UI list item components are properly memoized.
